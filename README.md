# 💻 C Programming Learning Journey (KBÜ)

Bu depo, Karabük Üniversitesi'nde aldığım dersler kapsamında C programlama dilinin temellerini öğrenirken ve pratik yaparken geliştirdiğim kodları içermektedir.

## 📂 İçerik Başlıkları

Depo içerisinde C dilinin temel ve orta seviye konularına ait örnekler yer almaktadır:
- **Temel Yapılar:** Kontrol yapıları (`do-while`, koşullar), diziler (`arrays`)
- **İleri Seviye Konular:** İşaretçiler (`Pointers`), Dinamik Bellek Yönetimi (`Dynamic memory allocation`), Yapılar (`Struct`)
- **Veri Yapıları & Algoritmalar:** Bağlı Listeler (`Linked list`), Sıralama algoritmaları (`Sorting`)
- **Dosya İşlemleri:** `FILE` yönetimi ve dosyalama işlemleri
- **Örnek Uygulamalar & Sınav Hazırlık:** `Exam preparation`, Fonksiyonlar ve özel algoritma pratikleri
